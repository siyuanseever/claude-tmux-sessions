## 正文

我同时用两个 Claude 账号推几个项目：一个账号管一个项目，账号下每个会话担一个职位，算法、后端、前端、测试各开一个。我只做判断，会话需要我的时候才过去。

会话一多，三件事最费神：
① 不知道谁在等我。权限框弹着，它干等了二十分钟。
② 不知道大家在干什么，只能一个窗口一个窗口切过去看。
③ 一个号的额度用完了，整条线停下。

于是给 Claude Code 写了一套 tmux 控制台：

🟥 底栏：⏸ 在等你、✔ 做完没看、▶ 在跑，一直挂着
📋 选择器：一个键看完所有会话，按编号直接跳
📌 侧栏：眼前这个会话的每一轮、额度、git，点一轮主界面就滚过去
⇄ 换账号：额度用完点一下，同一个会话换到另一个账号接着聊

已经开源，三步装好，GitHub 搜 claude-tmux-sessions（作者 threedaycat）。
目前只在 macOS 上用过，界面是中文的。有问题欢迎留言～
