# 2026-10-25 要不要迁到 herdr：冻结本仓库，先拿现成插件试一周

## 决定

- **本仓库冻结新功能**，只修 bug 和性能，照常每天用。
- 在 [herdr](https://herdr.dev)（0.9.5，Rust 写的终端复用器，定位是替代 tmux 这一层，并识别 agent 状态）里试一周。
  能用现成插件的用插件，缺的部分以后再写成 herdr 插件，不在 tmux 上继续加。

## 依据

herdr 自带、本仓库在 tmux 上做不好的：后台常驻 + 重启后恢复布局并接回 Claude 会话（自己存 `session.json`，
不用 resurrect + continuum + `restore-claude.sh` 三件拼接）、自定义浮窗只需几行配置（本仓库 `bin/float-tool.sh` 193 行）。

本仓库更好的：状态来自钩子（区分 blocked / input、跟踪子代理），herdr 主要靠读屏幕。

实测资源（2026-10-25）：

| 进程 | 内存 | CPU |
|---|---|---|
| `sidebar/trail_daemon.py` | 25 MB | 38.7 小时累计 198 分钟，平均约 8.5% 单核 |
| 侧栏 fzf × 11 | 约 85 MB | 每个约 0.07% |
| tmux server | 约 13 MB | 7 天累计 104 分钟，约 1% |
| herdr server + client | 约 43 MB | 37 分钟 13 秒，约 0.6%（只管 1 个 agent，负载不对等） |
| Claude Code × 18 | 约 3.9 GB | — |

管理层换哪个都只占总内存的 1–3%，省内存的办法是少开 Claude，不是换复用器。

## 什么证据出现就重启开发

- 试用一周后，在 herdr 里**每天**都想要轨迹侧栏或账号切换 → 把它们写成 herdr 插件（`placement = "split"` 常驻窗格），不在 tmux 上写。
- herdr 读屏幕判断的 blocked 漏报或误报，影响到"谁在等我" → 给 herdr 写一个基于 Claude 钩子的状态上报。
- 决定不迁、长期留在 tmux → 才恢复本仓库的新功能开发。

  所以第二阶段先把 `herdr/` 做成自成一体（不 import 本仓库的 `sidebar/`、`hooks/`、`lib/`、`bin/`），

- **UI 向 herdr 看齐，走终端的布局逻辑**：用户不喜欢 herdr-sidebar 那种 VS Code 式的 GUI 侧栏，
  要 lazygit、yazi 那样的终端布局。claude-trail 的颜色、状态点、边框尽量和 herdr 自己的界面一致
  （herdr 的调色板语义见 herdr v0.9.5 `src/app/state.rs:35-74`：green 完成 / 空闲，yellow 工作中，red 等你，accent 高亮）。
  用户原话的意思是「现在做的也能用」，所以是小步对齐，不推倒重来。
- **只显示 herdr 没有的东西，不重复造轮子**（用户 2026-10-25 晚）：Claude 的运行状态（工作中 / 等你 / 完成）herdr 左侧
  Agents 栏已经有，claude-trail 不再显示（窄版表头的状态图标已删）。claude-trail 专注会话轨迹和 herdr 没有的额度、上下文。
- **按钮开的工具不用 herdr 的 popup**：popup 只能居中、是整个会话的模态窗口，盖住 Claude、点外面也不关、鼠标退不出来。
  改成开在 Claude 右边（占 Claude 那一块的 60%），点外面（焦点挪走 0.4 秒后复查）就关；lazygit 叠加 `quitOnTopLevelReturn`，
  和 yazi 一样 Esc / q 都能退。代价：herdr 0.9.5 没有 tmux 那种不挤别人的浮动窗格，Claude 会暂时变窄、重新换行。
- **herdr 版只在 `siyuanseever/statetrail` 维护**（用户 2026-10-25 确认）：`herdr-plugin` 分支已合进本仓库 main 留下开发历史，随后删掉 `herdr/`，

## Ctrl+点击打开文件（2026-10-27）

- 问题：herdr 里 Cmd+点击路径打不开文件，Claude Code 回复里最常要跳的就是文件。原因在 herdr，不在 Ghostty：
  鼠标归 herdr（点链接是 Ctrl+点击）；herdr 不认纯文本路径（#609 等 Ideas 讨论没结论）；`file://` 要插件接；
  herdr 0.9.2 起 Claude Code 不输出链接（#4748）。
- 做法：`FORCE_HYPERLINK=1` 放进 Claude Code 的 settings.json；CLAUDE.md 要求提到文件写成 `[路径:行](file:///绝对路径#L行)`；
  dotfiles 新插件 `herdr/plugins/file-link` 接 `file://`（文本开 nvim 到行号、md 用 Typora、其余 `open`）。
  细节和排查见 dotfiles 的 `herdr/plugins/file-link/README.md`。dotfiles 提交 9e133ed、179022c。
- 验证：用户重启会话后亲手 Ctrl+点了文本带行号、脚本、Markdown、目录、网址五种，都打开了。
- 没解决：工具输出和其它程序打印的纯文本路径仍点不了，等 herdr；悬停没有下划线（#5329）。
